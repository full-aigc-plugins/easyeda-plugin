# easyeda-netlist-review

分析原理图网表、器件连接关系、电源网络和悬空引脚；默认只读检查。

## 首次使用

读取 [原生 MCP 约定](references/native-mcp.md)，按真实工具返回执行 help、doctor、session.list。
不要把工程为空或扩展未安装解释为需要切换到 WebSocket Gateway。

## 当前任务

需要明确：当前板子或指定图页；需要重点检查的网络与规则。

1. 查询当前工程、板子与图页范围。
2. 读取网表和网络信息，区分器件与网络标识符。
3. 按实际作用域合并跨页网络，核对短接符号。
4. 列出单连接、孤立引脚、悬空标签和关键电源路径。
5. 需要可视化时提供拓扑摘要；高亮动作遵循用户范围。

## 验证结果

- 报告包含具体位号、引脚和网络。
- 跨板同名网络未被错误合并。
- 未把 NC 引脚当成所有情况下的错误。

## 容易出错的地方

- 网络名存在不等于有实际对端。
- 高亮会改变显示状态，纯只读任务可仅报告。

## 使用示例

“只读分析原理图，找出供电网络和可能漏接的信号。”
