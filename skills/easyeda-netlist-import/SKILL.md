# easyeda-netlist-import

把已知 EasyEDA 网表重建为原理图，并处理器件查找、引脚映射和部分导入失败。

## 首次使用

读取 [原生 MCP 约定](references/native-mcp.md)，按真实工具返回执行 help、doctor、session.list。
不要把工程为空或扩展未安装解释为需要切换到 WebSocket Gateway。

## 当前任务

需要明确：网表文件及格式；目标工程与新图页；库器件匹配规则。

1. 识别网表格式与组件、引脚和网络结构。
2. 优先用明确供应商编号匹配器件，歧义结果不得选首项冒充确定。
3. 记录每个器件的导入成功、跳过和错误。
4. 回读引脚并创建网络，保留用户网络命名语义。
5. 导出实际网表与输入比较并报告差异。

## 验证结果

- 没有静默遗漏器件或引脚。
- 位号和封装匹配。
- 全部预期连接得到验证。

## 容易出错的地方

- 上游导入器会跳过失败器件，不能直接当成完整成功。
- 自动统一大小写可能合并原本不同的网络。

## 使用示例

“把这份 .enet 导入新图页，列出无法匹配的器件。”
