# 元件布局与网络扇出细则

此流程整理自官方 schematic fanout 技能；实际执行替换为内置 MCP。位置、引脚和网络映射必须来自真实器件库与用户电路需求。

## 生成顺序

1. 按 LCSC 编号批量查询器件，检查缺失项及返回的符号/封装，不能按数组位置盲配。
2. 先划分电源、接口、主控等模块，再放器件，给引脚、扇出线和文字留下空间。
3. 创建后读取实际图元 ID，使用异步状态提交位号，再按 ID 获取全部引脚。
4. 建立 `位号:引脚号 → 网络` 表；相同引脚名不代表相同引脚号。未连接引脚保留明确状态。
5. 根据引脚端点和旋转方向放置电源符号或网络端口，创建短连接导线；重新读取网表验证。

## 方位与单位

原技能的原理图单位为 10mil，建议的扇出距离 10 单位相当于 100mil。它是起点，不是所有符号的固定要求。

| 引脚 rotation | 扇出相对方向 |
|---|---|
| 0 | x 增大 |
| 180 | x 减小 |
| 270 | y 减小 |
| 90 | y 增大 |

先用当前器件的真实坐标验证方向；旋转、镜像和画布轴向均可能影响视觉判断。

## 修改已有图页

删除元件通常不会自动删除配套端口与导线。先读取旧端口/导线的 ID、坐标和网络，建立关联后删除目标旧对象，再生成新连接。仅凭坐标邻近不能断定所有权，靠近其他器件的对象尤其需要核对。

原理图 getAll 可能把网络旗标和端口也算作 component；统计真实器件时单独识别，不能把旗标数量算作 BOM 器件数。四脚轻触按键同一极的两个引脚内部相连，必须按具体 datasheet 分极，不能把电源与地分配到同一极。

## 检查

核对位号唯一、每根短线实际触及引脚端点、标签网络与网表一致、旧线已清理、模块框未遮挡文本。扇出可用于跨模块网络，局部电路优先保留易读的实际连线。
