# IMAGE 图片

`IMAGE` 和 `REGION` 极为类似，但是在操作上，`IMAGE` 不存在控制点，不能自由改变其形态，只能进行整体性的放大、缩小、旋转、翻转、平移等操作。

当 `IMAGE` 在信号层时，在 DRC 视角下，为一个无网络的，由起始、结束、旋转角度、是否镜像定义的矩形区域。

## 格式

```json
["IMAGE", "e100", 0, 31, 200, 200, 400, 400, 45, 1, 复杂多边形, 0]
```

## 字段说明

1. `IMAGE`：图片标识。
2. 图元编号。
3. 分组编号：`0` 不分组，非 `0` 为组标志，相同组标志的为一组。
4. 层。
5. 左上 X。
6. 左上 Y。
7. 宽。
8. 高。
9. 旋转角度，绕起始点旋转。
10. 原始图片是否水平镜像，镜像以原始图片 BBox 中点进行水平镜像。
11. 请参考复杂多边形章节，这里存储的是原始数据，整个生命周期不需要调整。
12. 是否锁定。
