# DIMENSION 尺寸工具集

## 格式

```json
["DIMENSION", "e101", "RADIUS", 3, "mm", 0.5, 3, 1, [100, 200, 300, 400, 400, 400], 0]
```

## 字段说明

1. `DIMENSION`：尺寸工具标识。
2. 图元编号。
3. 尺寸类型：`RADIUS` 半径、`LENGTH` 长度、`ANGLE` 角度。
4. 层。
5. 单位：`mm`、`cm`、`inch`、`mil`。
6. 线宽。
7. 精度。
8. 文字是否跟随：`1` 工具自动决定文字的位置，`0` 永远采用 `ATTR` 的位置。
9. 坐标集 `X1 Y1 X2 Y2 X3 Y3 …`，不同尺寸类型对坐标有不同的定义。
10. 是否锁定。

## 尺寸属性

`DIMENSION` 需要附带一个 Key 为 `VALUE` 的属性，表达尺寸工具的文字部分。EDA 需要忽略其不需要的属性，例如是否显示 Key、是否显示 Value。

```json
["ATTR", "e102", 0, "e101", 1, 200, 150, "VALUE", "1234mm", 0, 1, "宋体", 50, 10, 0, 0, 0, 2, 15, 1, 1]
```

## 尺寸类型

- 半径工具：坐标集第一个坐标为和 ARC 接触的端点，最后一个坐标为默认显示文字的端点。
- 长度工具：坐标集只需要具有四个点。
- 角度工具：坐标集需要 3 个点。
