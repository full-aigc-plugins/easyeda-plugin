# ITEM_ORDER 图元顺序建议

提供给 PCB 图元顺序建议，PCB 可以依照这个信息安排图元顺序。这个信息只能出现一次。

## 格式

```json
["ITEM_ORDER", ["e1", "e10", "e50", "e40e23", "e6"]]
```

## 字段说明

1. `ITEM_ORDER`：图元顺序建议标识。
2. 图元编号：有两种编码形式。
   - 普通编号：形式为 `/^[a-z]+\d+$/i`，如 `e1`、`e123` 等。
   - 封装实例编号：形式为 `/^[a-z]+\d+[a-z]+\d+$/i`，用于如封装中的丝印等，如 `e1e5`、`e12e22` 等。

这里说明下为什么叫做“建议”。因为比如 `e1` 是顶层图元，`e2` 是底层图元，那么：

```json
["ITEM_ORDER", ["e2", "e1"]]
```

默认依然是 `e1` 在上面，除非有什么特殊操作导致底层置顶了。
