# VIA 过孔

过孔一般用于打通不同层之间的电路。对于多层板一般有如下几种模式：

- 通孔：开始层到结束层贯穿顶层底层。
- 盲孔：开始层或结束层只有一个属于顶层或底层。
- 埋孔：开始层和结束层都不属于顶层或底层。

## 格式

```json
["VIA", "e100", 0, "GND", "asdf", 100, 200, 5, 9, 0, null, null, null, null, 0]
```

## 字段说明

1. `VIA`：过孔标识。
2. 图元编号。
3. 分组编号：`0` 不分组，非 `0` 为组标志，相同组标志的为一组。
4. NET。
5. 过孔层类型：设计规则名称，定义过孔的开始层结束层。
6. 坐标 X。
7. 坐标 Y。
8. 孔直径。
9. 焊盘直径。
10. 过孔类型：`0` 普通过孔、`1` 缝合孔。
11. 顶层阻焊扩展：`null` 为遵循规则。
12. 底层阻焊扩展：`null` 为遵循规则。
13. 是否锁定。

## 示例

```json
["VIA", "e101", 1, "VCC", "fdsa", 100, 200, 5, 9, 1, null, 0.5, 0.4, null, 0]
```
