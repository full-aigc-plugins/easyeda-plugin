# SHELL_ENTITY 外壳实体区域

没有通过 `CONNECT` 与 `CREASE` 关联的 `SHELL_ENTITY`，则垂直进行顶层、底层外壳的填充/裁剪（挖槽）。

## 格式

```json
["SHELL_ENTITY", "e35", 0, 50, 0, 0, 10, 10, 复杂多边形, 0]
```

## 字段说明

1. `SHELL_ENTITY`：外壳实体区域标识。
2. 图元编号。
3. 分组编号：`0` 不分组，非 `0` 为组标志，相同组标志的为一组。
4. 层编号。
5. 布尔操作：`0` 裁剪、`1` 填充。
6. 隶属：`0` 自动、`1` 上壳、`2` 下壳、`4` 外壳边框、`8` 螺丝柱、`16` 实体，可通过加法组合。
   - 上下壳：`3 = 1 + 2`
   - 外壳边框 + 螺丝柱：`12 = 4 + 8`
   - 螺丝柱 + 实体：`24 = 8 + 16`
   - 外壳边框 + 螺丝柱 + 实体：`28 = 4 + 8 + 16`
7. 深度。
8. 线宽。
9. 参考复杂多边形。
10. 是否锁定。
