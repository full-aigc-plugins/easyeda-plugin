# NET 配置网络信息

网络信息和 AD 的设计有区别：AD 这里是必选的，本格式只是需要有特殊网络类型和网络颜色才填写上去。设计差异的原因在于是否有一个专门的网络设置界面，会列出所有网络去设置。

## 格式

```json
["NET", "A", "High Speed", "#666666", 0, "AASDF", 1, "ABC"]
```

## 字段说明

1. `NET`：网络配置标识。
2. 网络名称。
3. 网络类型：`null` 为无类型。
4. 特殊颜色：`null` 为无特殊颜色。
5. 是否隐藏飞线。
6. 差分对名称：`null` 为非差分对。
7. 是否差分对正极。
8. 等长组名称：`null` 为非等长组。

## 示例

```json
["NET", "A", "High Speed", "#666666", 0, "AASDF", 1, "ABC"]
["NET", "B", null, "#666666", 1, "AASDF", 0, "ABC"]
["NET", "C", "High Speed", null, 1, null, 0, null]
```
