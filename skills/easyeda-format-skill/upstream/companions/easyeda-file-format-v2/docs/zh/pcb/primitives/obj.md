# OBJ 二进制内嵌对象

将文件等数据编码到图页上，以内嵌于图页上的图片和文件，可作为附件下载，以及直接显示。

## 格式

```json
["OBJ", "e662", 0, 15, "a.png", 200, 300, 10, 20, 0, 1, "blob:1234ade2f", 1]
```

## 字段说明

1. `OBJ`：二进制内嵌对象标识。
2. 图元编号。
3. 分组编号：`0` 不分组，非 `0` 为组标志，相同组标志的为一组。
4. 层。
5. 文件名。
6. 左上 X。
7. 左上 Y。
8. 宽。
9. 高。
10. 旋转角度，绕左上点旋转。
11. 原始图片是否水平镜像，镜像以原始图片 BBox 中点进行水平镜像。
12. 二进制数据：
    - 一般格式，与 Data URLs 完全兼容：`data:[<mediatype>][;base64],<data>`
    - BLOB 引用格式：`blob:hashid`
13. 是否锁定。
14. BBox（可选）。
