# 修订日志

## 2022111701

- 添加设计规则模板 `RULE_TEMPLATE`。
- 添加焊盘的专用热焊规则，包括连接方式、发散间距、发散线宽、发散角度。

## 2022111601

- `ARC` 的变种 `CARC`：老的 `ARC` 固定表示两点交互模式，新的 `CARC` 固定表示中心交互模式。

## 2022110101

- `REGION` 将禁止类型 1 和 4 拆分。

## 2022101701

- PCB 格式升级到 1.6。
- 重新设计字体缓存 `FONT`。

## 2022083001

- 扩展 `PREFERENCE`，丰富布线拐角模式，添加拉伸导线最小拐角比率。

## 2022082901

- 扩展 `CANVAS`，添加 Alt 栅格尺寸等。
- 扩展 `PREFERENCE`，添加布线、吸附、旋转等。

## 2022082601

- 版本升级到 1.5。
- 多边形“倒角比率”调整为“圆角半径”，注意解析兼容性。
- `LAYER_PHYS` 添加内电层是否保留孤岛的信息，需要注意老格式没有这项信息，要做兼容性处理。

## 2022082201

- `LAYER_PHYS` 添加。

## 2022071301

## 2022062301

## 2022061701

- `POURED` 图元添加所属 `POUR` 的 ID。

## 2022061601

- 添加 `PREFERENCE` 偏好设置。
- 添加 `EQLEN_GRP`、`EQLEN` 等长结构。

## 2022060601

- 拓展 `SHELL_ENTITY` 图元的“隶属”字段，兼容性建议：
  - 旧格式 `SHELLCUT`，隶属默认为外壳边框 + 螺丝柱 + 实体：`28 = 4 + 8 + 16`。
  - 旧格式 `SHELL_ENTITY`，隶属为 `0`，因为目前尚未发布，所以直接当成外壳边框 + 螺丝柱 + 实体均未选择即可。

## 2022042901

- 废弃 `SHELLCUT` 图元。
- 新增 `SHELL_ENTITY` 图元，基本继承被废弃的 `SHELLCUT`，新添加了一个布尔操作属性，指明是裁剪（挖槽）还是填充。

## 2022042101

- `SHELLCUT` 调整。
- `SHELL_ENTITY` `SHELLCUT` 调整。

## 2022040601
