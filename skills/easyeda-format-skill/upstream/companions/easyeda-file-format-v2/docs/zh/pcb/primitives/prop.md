# PROP 附加图元属性

有一些图元属性非必须表达，且相对通用，则用 `PROP` 辅助描述。

## 格式

```json
["PROP", "e5", "#22ee44"]
```

## 字段说明

1. `PROP`：附加图元属性标识。
2. 被附加的图元编号：有两种编码形式。
   - 普通编号：形式为 `/^[a-z]+\d+$/i`，如 `e1`、`e123` 等。
   - 封装实例编号：形式为 `/^[a-z]+\d+[a-z]+\d+$/i`，用于如封装中的丝印等，如 `e1e5`、`e12e22` 等。
3. 特殊颜色。

## 示例

```json
["PROP", "e5", "#22ee44"]
["PROP", "e7e25", "#22ee44"]
```

如果要覆盖封装内的图元，则采用此复合编号的形式去描述。
