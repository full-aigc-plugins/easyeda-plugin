# ARC/CARC 圆弧线

圆弧借鉴 Eagle 的数学模型，以起始、结束为基准去描述。

- `ARC`：两点交互模式。
- `CARC`：中心圆弧交互模式。

## 格式

```json
["ARC", "e100", 3, "GND", 1, 100, 200, 300, 400, -170, 10, 0]
```

## 字段说明

1. 圆弧线标识：`ARC` 或 `CARC`。
2. 图元编号。
3. 分组编号：`0` 不分组，非 `0` 为组标志，相同组标志的为一组。
4. 网络。
5. 层。
6. 起始 X。
7. 起始 Y。
8. 结束 X。
9. 结束 Y。
10. 圆弧角：逆时针正，顺时针负。
11. 线宽。
12. 是否锁定。
