# BUSENTRY 总线接入标识

`BUSENTRY` 用于表达总线的分支接入点。

## 说明

- 浅黄色为 `BUS`。
- 绿色圆角菱形，以及其向右延伸的一个类似 `PIN` 的图形，为 `BUSENTRY`。
- 蓝色为 `Wire`。
- 端点为 `WIRE` 和 `BUSENTRY` 类似 `PIN` 的最右侧端点接触的那个端点的坐标。
- 因为 `WIRE` 和 `BUS` 可以是任意角度接入的，所以需要指定其旋转方向以和 `WIRE` 的接入方向一致，例如图内是 180 度。
- `BUSENTRY` 固定一格长。
- `BUSENTRY` 具体的图形由 XTools 最终解释，不在格式内限定。

## 格式

```json
["BUSENTRY", "e380", "e271", 4, 500, 600, 90]
```

## 字段说明

1. `BUSENTRY`：图元名称。
2. 编号：文件内唯一。
3. 隶属编号：隶属于哪个 `BUS`。
4. 顺序编号：在隶属的 `BUS` 里的顺序编号，可重复。
   - 例如 `BUS` 网络为 `A[2:3]B[7:6]` 时，可以具有 `0 1 2 3 0 1 2 3 …` 一系列顺序编号的 `BUSENTRY`，其中：
     - `0` 代表分支 `A2B7`
     - `1` 代表分支 `A2B6`
     - `2` 代表分支 `A3B7`
     - `3` 代表分支 `A3B6`
5. 端点 X。
6. 端点 Y。
7. 旋转角度：绕端点旋转。
