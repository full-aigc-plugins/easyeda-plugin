# WIRE 导线

## 格式

```json
["WIRE", "e170", [[310, 550, 400, 550, 400, 460], [480, 460, 400, 460], [400, 330, 400, 460]], "st004", 0]
```

## 字段说明

1. `WIRE`：图元名称。
2. 编号：文件内唯一。
3. 坐标：分成多段线，每段都是连续的一组 `X1 Y1 X2 Y2 X3 Y3 …` 描述的线。
4. 线型样式编号。
5. 是否锁定。

## 网络属性

导线必须带上 `NET` 属性标识网络名称：

```json
["ATTR", "e199", "e170", "NET", "GND", 1, 1, 300, 200, 0, "st002", 1]
```
