# LINESTYLE 线型样式

线型样式与字体样式类似，是文件级的抽象，用于压缩格式内容尺寸。

## 格式

```json
["LINESTYLE", "st004", "#880000", 0, "#664400", 1]
```

## 字段说明

1. `LINESTYLE`：样式标识。
2. 字体样式编号：全文件唯一。
3. 颜色。
4. 样式：`0` 实线、`1` 短划线、`2` 点线、`3` 点划线。
5. 填充颜色：`""` 表示不填充；填充时自动闭合起始点和结束点。
6. 宽度。

## 示例

```json
["LINESTYLE", "st005", "#880000", 1, "", 1]
["LINESTYLE", "st006", "#880000", 0, "#664400", 5]
```
