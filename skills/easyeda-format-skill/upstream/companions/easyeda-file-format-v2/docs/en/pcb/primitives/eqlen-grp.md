# EQLEN_GRP

## Format

```json
["EQLEN_GRP", 1, "equal length pad group 1"]
```

## Field Descriptions

1. `EQLEN_GRP`: equal-length group identifier.
2. Equal-length group ID: unique within the file.
3. Equal-length group name.

## Examples

```json
["EQLEN_GRP", 1, "equal length pad group 1"]
["EQLEN_GRP", 2, "equal length pad group 2"]
```
