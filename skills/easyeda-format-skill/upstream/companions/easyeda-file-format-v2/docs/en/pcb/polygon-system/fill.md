# FILL Fill

## Format

```json
["FILL", "e100", 5, "GND", 3, 0, <complex polygon>, 0]
```

## Field Descriptions

1. `FILL`: fill identifier.
2. Primitive ID.
3. Group ID: `0` no group, non-`0` group marker.
4. Net.
5. Layer.
6. Line width.
7. Fill mode: `0` solid fill, `1` grid fill, `2` internal plane fill.
8. See Complex Polygon chapter.
9. Locked.
