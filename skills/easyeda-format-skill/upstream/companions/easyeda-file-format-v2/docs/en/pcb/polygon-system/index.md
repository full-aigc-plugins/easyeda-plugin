# Polygon System

SVG `path` is an excellent abstraction for polygons. However, because PCB does not need features like relative coordinates, and a more parseable format is desirable, a polygon representation similar to SVG `path` was created.

Within the polygon system, `POLY`, `REGION`, and `POUR` can be converted into each other.
