# SILK_OPTS

Silk options are mainly used for the color silkscreen process.

## Format

```json
["SILK_OPTS", 3, "#ffffff", "#000000"]
```

## Field Descriptions

1. `SILK_OPTS`: silk options identifier.
2. Layer: only top silk and bottom silk.
3. Default color.
4. Background color.

## Examples

```json
["SILK_OPTS", 3, "#ffffff", "#000000"]
["SILK_OPTS", 4, "#020202", "#aaaaaa"]
```
