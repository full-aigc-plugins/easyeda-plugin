# CANVAS Canvas Configuration

## Format

```json
["CANVAS", 0, 0, "mm", 10, 10, 1, 1, 0.1, 0.1, 1]
```

## Field Descriptions

1. `CANVAS`: canvas identifier.
2. Canvas origin X.
3. Canvas origin Y.
4. Display unit (does not affect the unit of data in the format).
5. Grid size X.
6. Grid size Y.
7. Snap grid size X.
8. Snap grid size Y.
9. Alt snap grid size X.
10. Alt snap grid size Y.
11. Grid type: `0` none, `1` grid, `2` dots.
