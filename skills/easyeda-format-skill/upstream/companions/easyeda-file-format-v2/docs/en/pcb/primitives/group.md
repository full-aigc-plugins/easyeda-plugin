# GROUP

Groups primitives and gives each group a name. If unnamed, the EDA tool decides how to display the default group name.

## Format

```json
["GROUP", 2, "ABCD"]
```

## Field Descriptions

1. `GROUP`: grouping identifier.
2. Group ID.
3. Name.

## Examples

```json
["GROUP", 2, "ABCD"]
["GROUP", 5, "中文名称"]
```
