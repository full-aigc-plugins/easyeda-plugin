# POLY

## Format

```json
["POLY", "e173", [390, 260, 450, 300, 560, 280, 540, 320], 0, "st005", 0]
```

## Field Descriptions

1. `POLY`: primitive name.
2. ID: unique within the file.
3. Point set coordinates: `X Y X Y X Y …`.
4. Whether to auto-close: if yes, the end point automatically connects to the start point.
5. Line style ID.
6. Locked.
