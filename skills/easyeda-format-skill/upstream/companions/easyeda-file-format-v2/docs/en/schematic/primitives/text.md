# TEXT

## Format

```json
["TEXT", "e171", 108, 804.5, 0, "any text", "st002", 1]
```

## Field Descriptions

1. `TEXT`: primitive name.
2. ID: unique within the file.
3. Text X coordinate.
4. Text Y coordinate.
5. Rotation angle, around the text coordinate.
6. Text content: any characters.
7. Font style ID.
8. Locked (optional).
