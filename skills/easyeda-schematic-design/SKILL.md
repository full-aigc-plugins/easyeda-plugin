# easyeda-schematic-design

将明确的电路需求转成器件、引脚连接与可编辑原理图；适用于 MCU 最小系统、电源和传感器接口设计。

## 首次使用

读取 [原生 MCP 约定](references/native-mcp.md)，按真实工具返回执行 help、doctor、session.list。
不要把工程为空或扩展未安装解释为需要切换到 WebSocket Gateway。

## 当前任务

需要明确：供电、电流、接口与功能参数；器件或模块约束；目标工程与图页。

1. 形成器件表及 位号:引脚号→网络名 的结构化连接描述。
2. 优先查询实际库器件和经过核实的复用电路。
3. 按功能块放置并读取真实引脚坐标。
4. 生成导线、标识符和必要参数，再导出实际网表比对。
5. 进行原理图 DRC；需要时验证计算和仿真。

## 验证结果

- 实际网表与连接描述一致。
- 关键电源、复位、上拉和去耦有明确依据。
- 工程可在客户端继续编辑。

## 容易出错的地方

- DRC 不证明电路功能正确。
- 不同芯片或封装的同名引脚不可仅凭外形匹配。
